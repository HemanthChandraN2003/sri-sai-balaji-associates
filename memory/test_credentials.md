# Test Credentials

This is a **frontend-only marketing website** for Sri Sai Balaji Associates.

- No authentication / login exists.
- No backend or database is used.
- The Quote/Enquiry form is a **DEMO** — on submit it shows loading → success but does **NOT** store data anywhere (clearly labelled in the UI).

## Configuration
All editable business data lives in: `/app/frontend/src/config/business.js`
Unknown values are intentionally shown as `[VERIFY ...]` placeholders (phone, WhatsApp, address, hours, Google rating, maps embed, review URL, email, socials).
